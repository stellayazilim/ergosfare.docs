<CardGrid stagger>
  <Card title="Compile-time registration" icon="seti:c-sharp">
    A Roslyn generator discovers handlers in your compilation *and* in referenced assemblies,
    pre-computes their descriptors, and emits `RegisterGenerated()`. A library's handlers
    register with no registration code in the library.
  </Card>

  <Card title="Reflection-free dispatch" icon="rocket">
    Generated dispatch roots close executor generics at compile time; pipeline plans pre-close
    generic handler types. No `MakeGenericType`, no registry scan, no `AsyncLocal` on the hot
    path.
  </Card>

  <Card title="Allocation you can account for" icon="approve-check">
    Pooled execution contexts and a `ValueTask`-first surface: 100k sequential dispatches
    allocate 2.3 MB, against MediatR's 18.3 MB for the same loop.
  </Card>

  <Card title="Nested dispatch, safely" icon="layers">
    `context.CreateScope()` gives a handler an isolated child context with inherited
    cancellation — the pattern ambient-state mediators cannot offer safely.
  </Card>

  <Card title="Native AOT and trimming" icon="setting">
    Every construct referenced statically via `typeof`; dispatch roots anchor every generic
    instantiation, `record struct` messages included.
  </Card>

  <Card title="Modular" icon="puzzle-piece">
    Commands, Queries and Events are independent packages over a shared core. `IModule` is a
    real extension point — the shipped modules use it too.
  </Card>
